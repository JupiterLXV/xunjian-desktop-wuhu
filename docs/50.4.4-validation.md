# 50.4.4 任务栏图标对照测试与交付

日期：2026-11-25（北京时间）。本次在当前主分支上增量修改，没有重新恢复项目。

## 结论与边界

已按要求移除 `app/main.cjs` 的整段 `win.setAppDetails()`，生成 50.4.4 Windows x64 测试安装包。保留原版 Logo、进程 `local.xunjian.desktop` AppUserModelID、`BrowserWindow.icon`、`win.setIcon()` 以及安装器快捷方式标识。

在真实 Windows Explorer 桌面任务栏中，50.4.4 显示原版 Logo，已保留任务栏截图。**但相同测试机上的旧版也显示正常，未复现用户电脑的白纸图标。因此，不能将 `setAppDetails()`、`appIconIndex: 0` 或某个 AppUserModelID 冲突认定为已证实根因，也不能声称目标电脑已彻底修复。此包用于目标电脑进一步验证。**

没有清理图标缓存，没有重启已有 Explorer，也没有重新设计或替换 Logo。
