# 50.4.5 加号杆号修复

日期：2026-11-26。基于当前主分支 `1f9ecdd` 增量修改。

## 根因与修改

`app/wuhu-core.js` 的 `parseLocation` 只接受 `#数字` 及既有的连字符、下划线、波浪线、字母等后缀，没有包含 `+`。因此 `#088` 有效，而 `#088+1`、`#088+2` 会返回 `{line:'',branch:'',pole:'',valid:false}`，目录分组、自动填写和命名均拿不到完整字段。已实际运行旧版与新版解析函数进行对照确认。

只扩展这一个共用校验表达式，支持 `#088+1`、`#088+2`、`#088+10` 以及无井号的 `88+1`、`88+2`；保留原有格式与合法性约束。加号作为杆号的一部分原样保留，不做加法运算，不去掉前导零，不改变源目录或源照片。

现有自然排序、完整杆号分组和进度统计无需修改。主线中的 `#087`、`#088`、`#088+1`、`#088+2`、`#088+3`、`#088+10`、`#089` 按此顺序排列，分别计为七基杆塔；每基全部照片看完才完成一基。三份成果按同一六字段名称保存，例如：

`10kV测试线-主线-#088+1-横担端U型挂板-螺母松动-严重.jpg`

未修改 `renderer.js`、目录树虚拟化、缓存/预加载/Worker 解码/导出、原图复制、模板、11 种主题、CSS、快捷键、报表或任何窗口图标配置。版本与测试、构建产物名称同步更新为 50.4.5。用户已暂停图标问题排查，本次不声称修复该问题。
