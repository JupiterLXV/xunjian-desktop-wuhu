## 性能与原 UI 保留

- 使用 Acorn 从原版和新版提取代码块，对解码 Worker、Decoder38、高清按需加载/释放、相邻预加载、预算/淘汰、FastIndex、VirtualTree48、Motion、缩放、布局和主题等进行 SHA256 相等校验；`getImage` 缓存主体单独核验。
- 普通浏览仍是 1440 像素预览，只有放大需要细节时才加载原图。保留 48–96 MiB 预览预算、最多 32 个缓存项、原高清释放和后台调度逻辑。
- 新预览只绘制现有缓存位图，不读取另一份原图；最终成对导出在 Worker 解码原始文件，依次编码，避免同时持有两个完整输出画布。
- 11 种主题、黑夜模式、原内嵌 CSS、背景资源、原图标、动效及快捷键保留。新增样式仅服务于裁剪面板。
- 授权模块、公钥、preload、激活页、激活脚本及原图标与原 ASAR 逐字节相同。
- 补充回归定位并修正了本次源选择接入中“刷新重置原图/成果视图选择”的状态问题：按照片保留手动视图偏好，切换两种视图和强制刷新均已验证；解码、缓存和预加载算法主体未改动。

## 构建与无法恢复的资料

原 ASAR 缺少 Electron 原始版本、devDependencies、锁文件、构建脚本、安装器原配置/升级身份及代码签名证书。已重新补齐：Node 24、Electron 45.5.0、electron-builder 26.18.0、Playwright 1.65.1、PNG 合成测试依赖与 AST 校验依赖；`package-lock.json` 固定版本。

标准 `npm run dist:win` 用于 Windows。受限 Linux 的 Wine 启动报 `wineserver: socket: Operation not permitted`；交叉构建脚本改为调用锁定 electron-builder 自带 UninstallerReader，提取真正的 NSIS 卸载器，再完成标准 NSIS 安装器链接。该构建环节不执行 Windows 程序，不作为 Windows 测试结果。

安装包没有代码签名，Linux 交叉构建关闭主 EXE 资源编辑；原图标仍用于运行界面，主 EXE 资源标识/旧安装器升级 GUID 无法保证完全等同原打包环境。没有伪造签名或签发许可证。

最终安装包附 `build-manifest.json`、`SHA256SUMS.txt`。构建核验检查包内每个应用文件与最终源码一致、版本正确、无测试/授权私密资料，且安装器为有效 PE 文件。文件结构/校验不等于运行成功；必须保留本节未验证项。
