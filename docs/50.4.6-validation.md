# 50.4.6 界面精简与应用改名

日期：2026-11-26。基于 50.4.5 主分支 4e20868 增量修改。

移除截图所示的上一张/下一张按钮、报告导出、更多工具及专注查看。相同功能的“分类整理”、设置中的文件名清理/全绝缘关键词及原生菜单报告入口同步移除，报告 UI、服务和 IPC 分支删除，避免其他入口继续调用。键盘快捷键、鼠标翻图与其他功能保留。

顶部工具栏首次默认展开，支持点击、Enter、Space 折叠/展开并记住状态。折叠只收起顶部操作区，两侧面板保留，杆塔进度条始终可见；后台保存及成果命名不切换实现。通过操作记录打开保存任务时自动展开工具栏，避免任务面板被隐藏。

应用名统一为“巡检缺陷工具-芜湖”，包括标题、品牌、EXE、安装/卸载器、桌面和开始菜单快捷方式。保持 package.name 与 AppUserModelID 不变，在改名之前保留原 userData 路径及显式配置路径，不新建另一套模板、已看记录或授权目录。原版 Logo 不变。

原版内嵌 CSS、11 种主题、背景图及 31 个性能/交互代码块继续执行原版校验，包括 1440 预览、按需高清、Worker、预加载、缓存淘汰和虚拟目录树。仅增加折叠区域的布局规则，未改解码、保存、裁剪、原图复制、加号杆号和模板实现。移除报告后暂不进行依赖升级或广泛依赖整理。

本地执行环境当前不可用。本次通过 GitHub 源码接口实际修改，并使用 Windows Actions 运行语法、单元、真实 Electron 回归、构建、旧版升级与新安装检查。完成结果、产物校验值和测试边界在构建结束后补充；尚未完成的步骤不记为通过。
